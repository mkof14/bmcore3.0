# Health Guide naming review (brief)

**Date:** 2026-08-03  
**Product UI name (current):** Health Guide  
**Parent brand:** BioMath Core  

## Decision

**Keep “Health Guide” in the product UI for now.** No clear *blocking* trademark or store listing was found that requires an immediate mass rename. Contingency names below are for counsel review if store filing or opposition arises.

This is **not** legal advice. Run clearance with trademark counsel before App Store / Google Play filing under the exact mark.

## Brief landscape findings

| Signal | Note |
|--------|------|
| **MOBE Health Guide** | Live on [Apple App Store](https://apps.apple.com/us/app/mobe-health-guide/id1457181693) and [Google Play](https://play.google.com/store/apps/details?id=com.mobeforlife.healthguide) (MOBE LLC). Close *compound* name in health coaching; not an exact “Health Guide” by BioMath Core, but relevant if we ship a native app titled only “Health Guide”. |
| **Generic descriptiveness** | “Health Guide” is highly descriptive in English wellness software. Descriptive marks are harder to monopolize — and harder to defend — but also face more third-party coexistence. |
| **Store policies** | Apple / Google can remove listings on trademark complaints even without a final court ruling. Health apps face additional Play / App Store health-content rules (declarations, disclaimers). |
| **USPTO / registries** | No substitute for a professional search in relevant classes (software / health services). A full clearance was **not** performed in this pass. |

## Contingency sub-brand names (if rename needed)

Use only if counsel or store conflict forces a change. Prefer keeping **BioMath Core** as company brand and renaming the in-product assistant:

1. **BioMath Guide** — closest to parent brand; clearer ownership.
2. **HDM Guide** — ties to Human Data Model; more unique, less descriptive.
3. **Twin Guide** — echoes digital-twin / Human Data Model positioning (verify conflicts).

Do **not** mass-rename UI strings without an explicit product decision.
